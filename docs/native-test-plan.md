## 本轮申请的范围

仅在本项目 `Tests/Fixtures/Synthetic` 和 `build/Fixtures/Large` 两个合成数据目录的 Finder 窗口中，模拟无修饰键的 `←`、`→`、`↑`、`↓` 和空格，包含短暂连续左右键。空格只用于打开、关闭合成文本文件的 Quick Look。每次输入前核对活动应用和测试窗口；焦点转移、未知窗口出现或用户操作时立即停止。

不涉及删除、重命名、输入文本或系统快捷键；不修改辅助功能或输入监控权限。权限修改、登录项、证书和公开发布仍各自遵守任务书确认规则。

## 原生行为对照

1. 关闭任何导航监听，仅以鼠标在测试窗口选择第一行末项。记录单选和全部图标坐标，按一次右键，读取实际结果。
2. 选择第二行首项，按一次左键并读回；与步骤 1 互为对照。
3. 分别验证行中左右键、首项左键、末项右键，不假定 Finder 原本是否换行。
4. 按名称、修改日期排序；按日期分组；排列为“无”分别记录。
5. 在鼠标产生多选后验证方向键；只记录 Finder 原生结果。
6. 打开 Quick Look，核对焦点，再测试左右键及空格关闭；记录预览与 Finder 选择是否同步。
7. 大型文件夹滚动边界测试；目标未加载时明确记录结果，不补造文件顺序。

## 实现后才执行的对照

正式事件监听实现后，重跑同一组步骤，核对仅确定的跨行事件被接管。测试快速连续左右键、焦点切换、窗口缩放及 Finder 重启后的缓存失效。写入失败必须有读回与事件处理证据；超时或读回不确定的情况不能按成功处理。

纯 Swift 引擎测试不代替以上系统测试。现有 4.2 ms 单次 AX 写入结果也不能证明键盘回调的延迟预算或原子性。
