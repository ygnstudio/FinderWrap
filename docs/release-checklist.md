# 发布检查表

当前为 **0.1.0 本地预览**。已有真实核心导航证据；以下发布门槛未全部达到，不能作为稳定发行版发布。

## 已完成的本地准备

- [x] 原生 Xcode 工程，最低部署目标 15.0，无第三方运行时依赖。
- [x] Release 应用与 probe 含 arm64/x86_64；lipo 和 otool 已核对架构、minos 及系统链接。
- [x] Finder AX 真实探查、选择写入/读回/恢复后才开始核心实现。
- [x] 36 个 XCTest；受约束的普通跨行、日期分组、短连续按键和放行场景实测。
- [x] 单页 SwiftUI 菜单栏内容、权限状态、显式启停、诊断和登录启动服务已实现。
- [x] MIT LICENSE、原创程序生成应用图标、版本号 0.1.0。
- [x] build/test/package/install/uninstall 脚本；安装拒绝覆盖，卸载默认预览并移至废纸篓。
- [x] GitHub Actions 配置准备完成；远端结果见对应提交的 [Actions 运行记录](https://github.com/ygnstudio/FinderWrap/actions)。
- [x] Universal 本地 ZIP、SHA-256、ad-hoc 签名核验。
- [x] 经用户确认安装到 ~/Applications，并在系统设置开启辅助功能/输入监控；登录启动保持关闭。
- [x] 菜单栏关联冲突已精确修复并备份；独立显示项、两次启动日志及用户打开面板已确认。
