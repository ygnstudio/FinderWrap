FinderWrap 1.0.1

在 Finder 图标视图中，用左右键自然跨行。

本地分发版 · Apple Silicon / Intel 通用构建
未使用 Developer ID 证书，未做苹果公证。仓库保持私有。

安装与开启

  1. 先退出正在运行的 FinderWrap。将磁盘映像中的 FinderWrap 拖入“应用程序”，再推出磁盘映像。
  2. 若已有预览版，请在原安装位置替换并保留旧版备份；例如原先安装在用户目录的 Applications 中，请继续使用该位置，避免保留两个可运行副本。
  3. 从 Finder 打开安装后的 FinderWrap。若系统阻止未公证应用，请核对来源及 SHA-256，再到“系统设置 → 隐私与安全性”使用系统提供的“仍要打开”。无需关闭 Gatekeeper 或 SIP。
  4. 点击菜单栏的折弯箭头，在“辅助功能”和“输入监控”中允许 FinderWrap，然后开启“左右键自动换行”。升级本地签名版本后，系统可能要求重新确认权限。

全新安装默认暂停，登录启动默认关闭；升级会保留原有导航偏好。点击面板内“退出”可完全停止监听。

怎么用

行末按 → 进入下一行首项，行首按 ← 返回上一行末项；首尾不循环。行内移动、上下键、组合键和多选保持 Finder 原生行为。

目前验证环境为 macOS 26.6.2 / Apple Silicon。最低编译目标 macOS 15；Intel、其他系统和更多显示器配置尚未完成实机验证。

支持范围

支持布局可确认的普通图标网格与已验证的日期分组。Quick Look、桌面、列表、分栏、自由排列、超过 160 项、屏外目标及不完整布局交给 Finder 处理，不强制滚动。

若本次选择无法确认，自动换行会暂停，原按键不再重复发送；这一次可能没有完成移动。请先检查选中项，后续按键仍由 Finder 正常处理，可在面板重新启用。

隐私与卸载

应用没有网络请求、遥测或账号，不保存文件名、路径、输入文本或键盘内容。诊断只含版本、权限状态、计数和耗时。

卸载前先关闭“登录时启动”并退出 FinderWrap，再将应用移到废纸篓。系统权限记录与偏好不会自动删除。
