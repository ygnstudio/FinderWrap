FinderWrap 1.0.5

仅 Apple Silicon，最低 macOS 13。图标视图全场景换行，不再限定测试目录。

  1. 退出旧 FinderWrap，备份旧应用，再将 FinderWrap.app 放入“应用程序”。
  2. 双击打开。只需授予辅助功能与输入监控两项权限；1.0.5 不再需要“自动化 Finder”（Apple Events）。
  3. 打开“左右键自动换行”。开关状态会记住，下次启动自动恢复；权限不全时保持关闭。
  4. 若旧包采用临时签名，迁移到固定证书可能需要重新授权。此包未经过 Apple 公证；系统阻止打开时，可在确认来源后通过“隐私与安全性”中的系统入口处理。不要关闭 Gatekeeper 或 SIP。

图标视图（普通/搜索/分组/桌面/Quick Look/多选）跨行换行并在文档首尾循环；画廊到头循环；列表左右键切上一项/下一项（端点不循环）；分栏与重命名保持原生。

应用只驻留菜单栏（无 Dock 图标与主窗口）：点菜单栏图标即可开关、查看权限与状态、复制诊断或退出。诊断不含文件名、路径与按键内容。不修改文件内容、不设置登录启动。
