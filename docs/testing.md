# 测试与交付

`bash scripts/test.sh` 运行核心 Swift 测试与分发保护测试，不访问 Finder、不发送系统按键、不操作钥匙串。`bash scripts/build.sh Release` 编译当前核心和宿主，核对 arm64 与 macOS 13；CI 固定签名使用既有证书，失败时禁止临时签名降级。

真实输入只在明确获准的脱敏目录验收。分别记录行内、前后跨行、分组、连按、滚动、失焦、编辑、多选、权限失效、监听暂停与用户主动暂停。不把源代码测试、只读采样、通知注册成功或安装启动当作跨行通过。

预览允许用户在普通文件夹自行使用；自动化验收范围不因此扩大。安装前备份旧包，退出已有实例，验证下载包摘要及固定证书，复制后再次验证，最后从安装路径启动。不得同时启用两份 FinderWrap；不得清除 TCC 数据来掩盖签名迁移问题。

开发缓存和旧编译副本可清理；签名材料、Git 历史、测试夹具、用户宣传素材以及最近一次回滚备份必须保留。
