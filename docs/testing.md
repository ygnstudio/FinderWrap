# 验收

## 自动化

```sh
bash scripts/test.sh        # Swift 单元测试 + 签名/最低系统 Python 测试
bash scripts/build.sh Release
```

Swift 测试覆盖纯逻辑：行聚类、跨行换行、拉不齐的末行、单行循环、多选锚点、重复 URL、非法几何、文档首尾循环。测试不访问 Finder、不发真实按键、不改权限。

## 实机清单（macOS 26 已过）

1. 普通文件夹图标视图：快速连按/按住左右键，行尾换行、行首回上一行、文档首尾循环。
2. 桌面：点桌面空白处后同样操作。
3. Quick Look：空格打开后左右键仍然跨行。
4. 分组/搜索窗口图标视图。
5. 多选后跨行。
6. 画廊视图：到头循环（开关打开）。
7. 列表视图：左右键切项（开关打开）；边界不丢选择。
8. 分栏、重命名、搜索框保持原生。
9. 「复制诊断信息」包含：状态、权限、布局行数/图标数、最近决策、AX 角色结构（不含文件名）。
