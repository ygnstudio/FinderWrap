# 兼容性与限制（1.0.4）

| 场景 | 行为 |
|---|---|
| 普通文件夹图标视图、单/多选、可见行边界 | 跨行换行，文档首尾循环 |
| 搜索、智能文件夹、iCloud 等图标视图 | 跨行换行（与普通文件夹同一路径） |
| 按种类分组的图标视图 | 行按 Y 坐标聚类，跨组继续换行 |
| 行被窗口边缘裁切 | 只要边缘行可读到几何就参与换行 |
| 桌面图标 | 支持（桌面图标表面不是 AXGrid，按焦点 AXGroup 识别，逐项写选择） |
| Quick Look | 支持（Quick Look 窗口属于 Finder，按键继续驱动底下的图标布局） |
| 画廊视图 | 缩略图条两端循环（可关闭）；左右键全接管，不依赖 Finder 光标 |
| 列表视图 | 左右键切换上一项/下一项（独立开关）；**端点按键被吞掉、不循环**（避免右键展开文件夹 / 写不可见行清空选择） |
| 分栏视图、重命名/搜索框等编辑态 | 保持 Finder 原生 |

已知边界：

- 列表首尾循环：Finder 26 对不可见行写 AXSelectedRows 会清空选择，分页键与 Apple Events 也无法可靠移动高亮；端点按键被吞掉以保持选择与确定性。
- 画廊循环采用 Finer 的做法：每次按键都读 AX 选择、算出目标并写回，再设容器焦点与滚动，因此不再受 Finder 键盘光标与高亮不同步的影响。
- 桌面与 Quick Look 依赖 AX 结构识别，系统大版本升级后需要用“复制诊断信息”复核。
- 仅 Apple Silicon，最低 macOS 13；本机 macOS 26 已实测，13/14/15 仍需实机回归。
