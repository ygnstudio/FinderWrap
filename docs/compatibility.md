# 兼容性与预览限制

| 场景 | 2.0.0 Preview 1 行为 |
|---|---|
| 普通文件夹、单选、可见且可确认的图标行边界 | 尝试增强；无需测试目录 |
| 可确认的相邻展开组边界 | 尝试增强；仍需实机回归 |
| 行内、列表、分栏、画廊、编辑、多选 | 原生交互 |
| Quick Look、桌面、屏外目标、无法确认的折叠组 | 原生交互，尚未增强 |
| 外部工具同时自动更改 Finder 选择 | 不作为支持场景；跨进程无原子事务 |

构建只含 arm64，Info.plist 和 Mach-O 最低系统均为 13.0。本机为 macOS 26；13/14/15/27 尚无新核心的真实按键验收，不以编译通过宣称兼容。预览版不自动更新稳定版 Release / Homebrew。
